# BigInt

An educational C++ arbitrary-precision unsigned integer class with constructors, indexing, addition, multiplication, stream input, and factorial/addition demonstration programs.

## Build and test

\`\`\`sh
make tests
make add
make multiply
make factorial
\`\`\`

The Makefile uses \`clang++\`; the implementation is in \`bigint.hpp\` and \`bigint.cpp\`.
